👋 I built the GBRSA Registration Portal — it's the online registration system for the GBRSA CUP 2026 Jump Rope Championships for my academy. It's a full-stack web app I made with Vue 3 (Composition API) + Vite + TypeScript, using Pinia for state management and Vue Router for the multi-step flow. Basically replaced the old Google Forms + spreadsheet mess with a proper system that validates everything, calculates fees automatically, and does the admin work for us.
