FlowScore × core-data — Profile & Digital ID

Draft mock-ups for connecting the FlowScore app to IJRU core-data: the account menu, profile and the IJRU ID. iOS screens follow iOS 26 (Liquid Glass chrome, inset grouped lists, form sheets). Android screens follow Material 3 (dynamic-colour surfaces, top app bar, extended FAB, snackbars). The ID card uses the FlowScore ink-and-coral palette from the app icon so it reads as one product. The QR codes here are placeholders: the real code is a signed, device-bound presentation that changes every 10 s.
