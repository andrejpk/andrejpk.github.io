Event Definition Lookup Codes

Event definition lookup codes are a standardized way to code an event definition (e.g. SRS 1x30, DDPF) in a way reliably between systems. They are encoded in this format:

e.[org].[type].[discipline].[event_abbr].[num_participants].[timing]

For example:

e.ijru.fs.dd.ddpf.4.75

Is the IJRU event Double Dutch Pairs Freestyle.

It's important to note that the event definition lookup code DOES NOT contain any information about which rules or judges etc are involved in the event

Organization, [org]

Organization's abbreviation is:

Abbr Organization
ijru International Jump Rope Union
rsc Rope Skipping Canada
ddc DDC World
sau Skipping Australia
amjrf American Jump Rope Federation
svgf Swedish Gymnastics Federation
ajru Asian Jump Rope Union

Event Type, [type]

Defines the type of event:

Abbr Type
sp Speed/Power/Endurance
fs Freestyle
oa Overall

Discipline, [discipline]

Defines the discipline of the event:

Abbr Type
sr Single Rope
dd Double Dutch
wh Wheel
lr Long Rope
ts Team Show Contest
xd Cross-Dicipline

Number of Participants, [num_participants]

This is the minimum number of participants required for the event.

Timing

Timing is a string for the total event length or the splits for a relay event, [splits]x[length] format, for example:

e.ijru.sp.dd.ddsr.4.4x30

For individual speed events (e.g. 1x30), omit the '1x'), for example:

e.ijru.sp.sr.srss.1.30

Overall/All-Around Events

Overalls are a special case of Event Definitions since they may not fall into a single discipline or event type and don't use timing. For example, the Team Single Rope Overall:

e.ijru.oa.sr.tsro.4.0
